# 覆盖边界

## 自动检查

### 资源与目录
- 固定磁盘剩余空间、剩余百分比、按历史样本外推的"还剩多少次体检写满"
- 内存快照、系统报告的启动时间
- 配置目录的逻辑大小与分配大小、顶层分布、最大文件、大日志、开发依赖
- 缓存目录（命名表或自定义路径）：npm、pip、uv、pnpm store、Playwright、Chrome、Edge、用户临时目录
- 运行时目录中的安装残留（`*-install-*`）与旧版本备份（`.previous-*`）

### 可回收判定
- A/B/C 分级与 `blocked`，每条含依据、再生方式、恢复方式
- 白名单与保护区排除、占用检测、两次观测计数

### 系统与稳定性
- 启动项名称、位置、可提取的可执行目标（不保存参数）
- 监听端口、可见进程路径
- 配置选中的计划任务路径与服务名称
- 系统日志近 N 天 Error/Critical 计数与 Top 来源
- 应用崩溃（Application Error / .NET Runtime / Windows Error Reporting）
- 页面文件使用率、句柄总数、近 10 次启动耗时中位数
- 物理磁盘健康状态与磨损（可用性取决于机型与权限）

### Skill 目录
- 同名 Skill、`SKILL.md` 哈希；只对哈希不一致的产生告警

## 需要另行核实

- "已删但仍被占用"的准确容量：没有等价于 lsof 的默认实现，不安装 Handle
- 回收站内容：只提示，不自动清空
- 浏览器站点离线数据：涉及浏览活动，默认不读
- AI 工具的私有自动化与会话库：只用宿主提供的管理入口
- 重复仓库、快捷方式、路径引用：不为体检遍历全局配置
- Skill 真实调用率、备份可恢复性、云盘同步状态、任务输出正确性：无证据即写未知
- 系统文件完整性（`sfc /verifyonly`）、Windows Update 清理、休眠文件：需要管理员或系统工具，默认关闭
- 温度、风扇、电池健康：依赖厂商驱动，不覆盖

## 报告中的建议

- 大文件、依赖、缓存只是候选，不构成删除建议
- 清理前确认：相关进程、启动项、任务、快捷方式是否引用
- 不使用会同步删除备份端的镜像命令
- 读取受限时写清缺口；不得把逻辑大小、缺失数字、单次快照改写成"能清理多少"或"有故障"

## 判断边界

- 分配大小是按簇对齐的估算，不等于可释放空间
- 不同扫描根、嵌套依赖可能重叠，不能相加
- 同名、同哈希、修改时间都不能单独证明可删
- 两次观测不证明期间状态持续，也不授权关闭任何程序
- 历史快照不等于用户认可的正常名单
